# «Убийства по алфавиту» — доски улик

Наглядная шпаргалка к викторине по роману Агаты Кристи «Убийства по алфавиту» (пер. А. С. Петухова).

- `boards/index.html` — оглавление: по одной «доске улик» на каждую из 34 глав.
- `boards/obshchaya-doska.html` — общая доска по всей книге: все персонажи, улики и места, их связи и действия, ползунок по главам и кнопка разгадки (спойлер!).

Все факты взяты из текста книги; у каждого указана страница. Цитаты сверены с текстом скриптом `boards/src/verify_quotes.py`.

## Как пересобрать

Данные — в `boards/src/data/chNN.json` (главы) и `boards/src/erd.json` (общая доска).

```
python boards/src/build.py
python boards/src/build_erd.py
```

Скрипты проверки (`verify_quotes.py`, `verify_names.py`) требуют локальную папку `book/` с текстом книги — она не хранится в репозитории из-за авторских прав.
